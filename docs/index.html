How to install

  1. On an OpenHop Repeater, install the ZorCore wheel from Releases and enable the plugin.
  2. Open /plugins/zorcore/, set up the companion, then copy the meshcore:// link or QR.

Full install steps: GitHub README.

How to play

  1. Advert yourself as a Chat Node first so Zork🕹️ can add you and reply. Once is enough before you start — you do not need to advert again for every new game. If you never get a reply, advert once more (the first one may have been too old, or never heard).
  2. Add Zork🕹️ from the operator’s meshcore:// link or QR.
  3. DM new game (also new / start / play).

Radio tips

  • Long story replies arrive as multipart DMs: 1/3… means more is coming; .3/3 means the story is complete.
  • Exits (and other status tips) are a separate unlabeled message — not part of the n/m count.
  • Lost a chunk? DM ? / hello? to resend the last reply. Use again / g to redo your last command.

Radio safety

Mesh airtime is shared. ZorCore limits how many players can generate game traffic at once so the dungeon does not flood the radio.

  • Play is DM-only to Zork🕹️ — no game spam on public channels.
  • Remote play opens only when OpenHop Adaptive Rate Limiting says the mesh is quiet enough; otherwise deeper-hop players wait in a FIFO queue.
  • Nearby players (path ≤ local_max_hops) can still get a local fast-pass when the mesh is busy for remotes, with a capped number of concurrent locals.
  • Single-player mode (when enabled) keeps one remote turn at a time; others are queued and DMed when a slot opens.

Shared dungeon · local fast-pass

Everyone shares one living world — same thief, troll, and cyclops. Remote players queue when the mesh is busy; companions within local_max_hops still get a fast pass.

Reuse / fork

Feel free to reuse this project to adapt other vintage Infocom-style text adventures for MeshCore — same radio chunking, companion DMs, and shared-world patterns. Forks and ports of other classic interactive-fiction titles are welcome.

The MIT license covers the plugin code. Story rights for third-party games stay with their owners; only ship text and assets you have the right to use.
